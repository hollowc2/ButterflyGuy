# Archived Schwab gateway transition records

These files are retained for rollback, audit, and provenance. They describe completed or superseded
transition work and are not current operating instructions. The current Butterfly Guy status is in
[`../../architecture/schwab-gateway-current-status.md`](../../architecture/schwab-gateway-current-status.md).

The archive preserves the original contents and dates. Do not update historical claims in place;
record new status in the current document instead.

It includes the extraction ledger, completed execution prompts, the superseded PAPER cutover
handoff, dated reauthorization/soak records, and obsolete gateway deployment/design runbooks.
The corresponding dated Python soak harnesses and launchers are under
`tools/archive/schwab-gateway/`; they are retained as release evidence, not supported commands.
